# 📊 Sales Performance Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive **Sales Performance Dashboard** built using **Microsoft Power BI**. The dashboard analyzes sales data to provide insights into revenue, profitability, regional performance, customer behavior, and product sales. It enables users to explore business performance through dynamic visuals and filters.

---

## 🎯 Objectives

* Analyze overall sales performance.
* Identify top-performing regions and sales representatives.
* Compare sales across product categories.
* Understand customer types and payment preferences.
* Monitor sales trends over time.
* Evaluate discounts.

---

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)

---

## 📂 Dataset

The dataset contains the following fields:

* Product_ID
* Sale_Date
* Sales_Rep
* Region
* Sales_Amount
* Quantity_Sold
* Product_Category
* Unit_Cost
* Unit_Price
* Customer_Type
* Discount
* Payment_Method
* Sales_Channel
* Region_and_Sales_Rep

---

## 📈 Dashboard Features

* KPI Cards (Total Sales, Total Profit, Total Quantity Sold, Average Discount)
* Sales Trend Over Time
* Sales by Region
* Sales by Customer Type
* Top Sales Representatives
* Customer Type Analysis
* Payment Method Distribution
* Sales Channel Performance
* Interactive Slicers for filtering data

---

## 📊 Key Insights

* Track sales trends across different time periods.
* Compare regional sales performance.
* Identify the best-performing sales representatives.
* Understand customer purchasing behavior.
* Measure discount impact.
